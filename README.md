# Числовые алгоритмы: эксперименты на Python

Программа к исследовательской работе по дисциплине «Алгоритмы и структуры данных»
(ПГГПУ, направление «Прикладная информатика и системы искусственного интеллекта», 1 курс).

Тема: «Числовые алгоритмы. Алгоритм Евклида. Алгоритмы факторизации и поиска простых.
Псевдослучайные числа. Методы перемешивания».

Выполнил: Осокин А.В., гр. 1214.

## Что делает программа

Всё находится в одном файле `main.py`. При запуске появляется меню из четырёх экспериментов:

1. **Алгоритм Евклида.** НОД через вычитание и через остаток: число шагов и время,
   худший случай на числах Фибоначчи, проверка оценки Ламе.
2. **Простые числа и разложение на множители.** Перебор делителей и решето Эратосфена,
   тест Миллера – Рабина (в том числе на числе Кармайкла 561 и на 2^61 − 1),
   разложение перебором и ро-методом Полларда.
3. **Псевдослучайные числа.** Линейный конгруэнтный генератор с параметрами Numerical Recipes
   и встроенный `random`: период (теорема Халла – Добелла), младший бит, критерий хи-квадрат, скорость.
4. **Перемешивание.** Алгоритм Фишера – Йетса и неправильный способ: частоты перестановок
   массива [A, B, C] (1/6 против 4/27 и 5/27) и время на больших массивах.

Пункт 5 запускает все эксперименты подряд (около 10 секунд). Графики сохраняются
в папку `графики` рядом с программой.

## Как запустить

1. Установить Python 3.10 или новее: https://www.python.org/downloads/
   (в Windows при установке отметить галочку «Add python.exe to PATH»).
2. Скачать репозиторий: зелёная кнопка **Code → Download ZIP**, затем распаковать архив.
3. Открыть командную строку в папке с программой и установить библиотеку для графиков:

   ```
   pip install -r requirements.txt
   ```

4. Запустить программу:

   ```
   python main.py
   ```

5. В меню ввести номер эксперимента (1–5) и нажать Enter. 0 — выход.

Случайные числа генерируются с фиксированным зерном, поэтому число шагов, количество простых,
периоды и частоты перестановок при каждом запуске совпадают. Время в миллисекундах зависит
от компьютера и будет немного отличаться.
